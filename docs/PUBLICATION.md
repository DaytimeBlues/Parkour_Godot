# Publication scope and rights

The owner requested this specific public repository for Godot Parkour on 9 November 2026. The repository was empty at preflight. This import is an additive, reviewed source snapshot, not a force-push or a replacement of the private development repositories.

## Included

The woodland beta's runtime scripts, project configuration, collision data, tests, local relay/serve/check tools and three project-owned GLBs. `SOURCE-MANIFEST.json` records exact source-file hashes and which publication files differ. The original local history and recovery archives remain preserved.

The GLBs are recorded in the existing project provenance as project-owned geometry. They are not the third-party animated fox used by the later animation lab. Their exact hashes are retained in `assets/PROVENANCE.json`. No blanket licence change is made. Public visibility alone is not an open-source licence.

## Deliberately excluded

- Private historical evidence, provider links, computer paths, local process records and unrelated projects.
- Credentials, environment secrets, authentication state and real student data.
- Generated Godot cache, Web engine binaries, export output, installers and virtual environments.
- Unintegrated animation/HTTP lab payloads and animation research assets whose release rights or recovery status remain unresolved.
- Automatic workflows, deployment configuration and production hosting credentials.

The selected project's local display-only relay is not a secure public multiplayer service. No source upload constitutes deployment or classroom readiness.

No existing screenshot of this exact beta was retained in the source record, so none is invented or substituted with animation-lab imagery. A future current-build image should be bound to its source and labelled separately from aspirational art.
